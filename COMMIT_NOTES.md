# What goes in a commit

`.gitignore` enforces most of this automatically.

## Commit

| Path | Why |
|---|---|
| `Detection/01_detect_Yolo/*.py`, `Detection/02_homography/*.py` | The pipeline code |
| `Detection/02_homography/GogEarth_points.kml` | Reference points picked in Google Earth (manual work) |
| `Detection/03_features/sdescript.yaml` | Feature config |
| `Data/Data_Config/paths.yaml`, `Data/Data_Config/homo_pick_points.json` | Config and hand-picked calibration points |
| `Detection/Outputs/H_C1.npy`, `H_C1_calib_utm.npy`, `study_area.geojson` | Small calibration results (KB) |
| `Naming Behaviors/` | Stage placeholders (empty files) |
| `pyenv_requirements.txt` | Python dependencies |
| `.gitignore`, `COMMIT_NOTES.md` | These rules |

## Don't commit (ignored)

| Path | Size | Why |
|---|---|---|
| `*.pt` (YOLO weights) | 190 MB | `yolov8x-pose.pt` exceeds GitHub's 100 MB file limit. Ultralytics downloads weights by name. |
| `Detection/Outputs/` everything else: detection CSVs, ground/study-area CSVs and GeoJSON, `check_*` images | about 50 MB | Regenerated by the scripts (see below) |
| `.DS_Store`, `__pycache__/`, `.ipynb_checkpoints/` | small | Machine clutter |

## Decide before committing

- **`expore_results.ipynb` (6.9 MB).** Almost all of that is embedded output images. Run *Clear All Outputs* and save first; it drops to a few KB.
- **`.vscode/settings.json`.** Sets your personal conda setup. It's harmless to share, but only useful to you.
- **`Behaviors/`.** Its subfolders are empty, and Git doesn't track empty folders. Add a `.gitkeep` file to each one if the structure should appear on GitHub.

## Not in the repo at all

- **WILDTRACK footage and calibration files.** They live on the external drive set in `Data/Data_Config/paths.yaml` (`/Volumes/Backup Drive/...`). The drive must be connected to run any script.

## Regenerating the outputs

Run from your project environment, with the data drive connected:

1. `Detection/01_detect_Yolo/01_detect.py` writes `detections_<camera>_yolov8m-pose.csv` and `check_frames_yolov8m-pose/`. Set `camera_dir` in `paths.yaml` to `.../C1` or `.../C6`.
2. `Detection/02_homography/homography_calibration_imported.py` writes `H_C1_calib_utm.npy`, `study_area.geojson` (4 m buffer), `detections_C1_ground_all.csv`, `detections_C1_study_area.csv`/`.geojson` and `check_study_area_*`. It needs `detections_C1_yolov8m-pose.csv`.
   - `homography_calibration_manual.py` is the older alternative. It writes `H_C1.npy` plus the **same** CSV, GeoJSON and image files with a 2 m buffer, so running it overwrites step 2's results.
